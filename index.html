Înainte de cod: cum lucrează calculatorul

CPU

Procesorul

Este „creierul” calculatorului. Citește programul tău linie cu linie și face exact ce scrie acolo, de miliarde de ori pe secundă.

Nu ghicește nimic: face doar ce îi spui. Poate să calculeze, dar nu ține minte numerele. Ce vrea să păstreze, pune în memorie.

123456

Memoria

Seamănă cu un dulap uriaș cu sertare mici, ca niște cutii. Fiecare cutie are numărul ei și ține un singur număr.

Procesorul poate să se uite într-o cutie (citire) sau să pună alt număr în ea (scriere). Numărul nou îl șterge pe cel vechi.

a5

Variabila

Este o cutie din memorie căreia îi dai un nume. int a; îi spune procesorului: „ia o cutie pentru un număr întreg și scrie pe ea a”.

De acum, când scrii a, procesorul știe în ce cutie să se uite. La început cutia e goală: aici primești eroare dacă o citești înainte să pui ceva în ea.

a←5

Atribuirea

a = 5; se citește „a primește 5”, nu „a este egal cu 5”. Procesorul face doi pași, mereu în ordinea asta:

  1. calculează ce este în dreapta semnului =;
  2. pune rezultatul în cutia din stânga.

Ca să întrebi „sunt egale?” se folosește ==, de exemplu în if (a == 5).

cba← vârf

Stiva

Cutiile variabilelor stau într-o parte a memoriei numită stivă. Ca la un teanc de farfurii: fiecare int nou pune o cutie deasupra celorlalte, în vârf.

O atribuire ca a = 6; nu pune o cutie nouă: schimbă numărul din cutia a, acolo unde stă ea pe stivă.

La }, cutiile luate în blocul acela sunt scoase de sus: ultima pusă pleacă prima. Locul lor se refolosește. Panoul „Memoria” de lângă program îți arată asta la fiecare pas.

Lecția despre stivă →

p•→a5

Pointerul

Numărul unei cutii se numește adresă. &a înseamnă „adresa lui a”. Un pointer este o cutie în care pui o adresă: int *p = &a; Spunem că p arată spre a.

*p înseamnă „cutia spre care arată p”. Așa, *p = 6; pune 6 în a, fără să scrii a. Grijă: dacă a fost scoasă de pe stivă, p arată spre o cutie care nu mai există.

p•→heap 17

Heap-ul

Mai există o parte a memoriei, heap-ul. int *p = new int(7); cere de acolo o cutie nouă, cu 7 în ea, și pune adresa ei în p. Cutia nu are nume: o folosești prin *p.

O cutie din heap nu pleacă la }. Rămâne până scrii delete p; Dacă uiți de ea, ocupă degeaba memoria până la sfârșitul programului.

        Ce poți folosi
        
    
        
      
        Variabile
        int a, b = 5;
        long long x = 1870413123455;
        
      
        Citire și afișare
        cin >> a >> b;

        Calcule
        +  -  *  /  %  ++  --  +=  -=  *=  /=  %=
        
      
        Comparații și logică
        ==  !=  <  <=  >  >=  &&  ||  !
        
      
        Decizii
        if (a > b) { ... } else { ... }
        
      
        Repetiții
        while (n > 0) { ... }
        for (int i = 1; i <= n; i++) { ... }
        do { ... } while (n > 0);
        break;  continue;
        
      
        Pointeri
        int *p = &a;  *p = 6;
        p = nullptr;  if (p != nullptr) { ... }
        
      
        Heap
        int *p = new int(7);
        long long *q = new long long;
        delete p;
        
      
        Funcții
        int suma(int a, int b) { return a + b; }
        void schimba(int *a, int *b) { ... }
        (scrise deasupra lui main)
        
    
        
    
        Aici lucrăm doar cu numere întregi: int (până la 2147483647) și long long, pentru numere mai mari (până la 9223372036854775807). Ca un calcul cu int să nu iasă din int, scrie (long long)a * b sau 1LL * a * b. Împărțirea / dă câtul, iar % dă restul. Numerele cu virgulă, caracterele, șirurile, vectorii (nici new int[n]), calculele cu pointeri (p + 1), pointerii la pointeri (int **), referințele (int &) și funcțiile din biblioteci (sqrt, max…) nu sunt disponibile.
