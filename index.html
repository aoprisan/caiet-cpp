    Ce poți folosi
    
    
    
      
    Variabile
    int a, b = 5;
    
      
    Citire și afișare
    cin >> a >> b;
    cout << "Suma: " << a + b << endl;
    
      
    Calcule
    +  -  *  /  %  ++  --  +=  -=  *=  /=  %=
    
      
    Comparații și logică
    ==  !=  <  <=  >  >=  &&  ||  !
    
      
    Decizii
    if (a > b) { ... } else { ... }
    
      
    Repetiții
    while (n > 0) { ... }
    for (int i = 1; i <= n; i++) { ... }
    do { ... } while (n > 0);
    break;  continue;
    
    
    
    
    Aici lucrăm doar cu numere întregi (int). Împărțirea / dă câtul, iar % dă restul. Numerele cu virgulă, caracterele, șirurile, vectorii și funcțiile proprii nu sunt disponibile.
